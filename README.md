# онлайн шлюшки — расписание и оценки

Статический сайт для GitHub Pages. Главная страница показывает расписание звонков, ищет баллы и проценты, отображает таблицу с поиском по фамилии и ведёт к домашним заданиям.

## Публикация на GitHub Pages

Workflow GitHub Actions настроен для автоматической публикации сайта при изменении файлов в ветке `main`. После загрузки проекта откройте **Settings → Pages** и выберите источник **GitHub Actions**.

После первого деплоя сайт будет доступен по адресу `https://ovsankax.github.io/sss/`.

Таблица загружается из Google Sheets напрямую в браузере; таблица должна быть доступна по ссылке для чтения. Имена и оценки отображаются посетителям сайта. В браузере сохраняются только тема и цвет акцента. Иконки лежат локально в `assets/icons`, лицензия приложена рядом.
